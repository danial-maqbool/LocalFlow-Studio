# Recorded media

Screenshots and demo.gif are recorded from the running application with synthetic example files.
Run `python scripts/browser_check.py --record` to replace them with a fresh recording.
Install Playwright Chromium first. Use --browser PATH for an existing compatible Chromium.
Use --bridge only on a test host that blocks direct loopback navigation. The report records that mode.
GIF frame timing is illustrative. The recording is not a performance benchmark.
No generated mockup or manually changed screenshot is presented as app evidence.
